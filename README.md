# Number Theory Calculator

A simple web-based calculator built using HTML, CSS, and JavaScript.

## Features
- Factorial
- HCF (GCD)
- LCM
- Step-by-Step Solution
- Calculation History
- Responsive UI

## Technologies
- HTML
- CSS
- JavaScript
